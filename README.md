# Ev Stok

Evdeki eksikleri ve alınacakları takip etmek için mobil uyumlu web uygulaması.

## Çalıştırma

```bash
npm install
npm run dev
```

## Mail hatırlatıcı

Günlük 15:30 / 17:30 mailleri için `.env.example` dosyasını `.env` olarak kopyalayıp Gmail uygulama şifresini girin, sonra:

```bash
npm run reminders
```
